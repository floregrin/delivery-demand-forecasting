# Data

Raw data is intentionally excluded from version control.

Download **Delivery Center: Food & Goods Orders in Brazil** from Kaggle and place the CSV files in:

```text
data/raw/delivery_center/
```

The main analysis uses `orders.csv`, `stores.csv`, `hubs.csv`, `deliveries.csv`, and `drivers.csv`. Processed files and the SQLite database generated by the notebook are written to `data/processed/` and are also excluded from Git.
